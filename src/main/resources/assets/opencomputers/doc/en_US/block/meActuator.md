# ME Actuator

![Now with 100% more everything, and connected.](oredict:oc:meActuator)

A [ME Transposer](meTransposer.md) with an [adapter](adapter.md) fused into it. In addition to moving items to and from an attached ME network through its virtual "me" side, it can interface with whatever block sits on its side the same way an adapter would, exposing it as a component to a connected [computer](../general/computer.md). This also applies when it's installed as a [microcontroller](microcontroller.md) upgrade: it scans the microcontroller's own six sides for interfaceable blocks the same way, connecting whatever it finds to the microcontroller's computer.

*Note that this block has no internal inventory, and requires Applied Energistics 2 to be installed.*
