# ME Actuator

![Now with 100% more everything, and connected.](oredict:oc:meActuator)

A [ME Transposer](meTransposer.md) with an [adapter](adapter.md) fused into it. It moves both items and fluids to and from an attached ME network through its virtual "me" side. It can interface with whatever block, the same way an adapter would, exposing it as a component to a connected [computer](../general/computer.md). An actuator can also report the network address of whatever's connected on a given side. This also applies when it's installed as a [microcontroller](microcontroller.md) upgrade.

*Note that this block has no internal inventory, and requires Applied Energistics 2 to be installed.*
