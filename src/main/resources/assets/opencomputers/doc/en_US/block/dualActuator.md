# Dual Actuator

![Twice the reach.](oredict:oc:dualActuator)

An [actuator](actuator.md) that also moves fluids between the ME network and the tank on its facing side, the same way an adapter with a [tank controller upgrade](../item/tankControllerUpgrade.md) could.

Like the [actuator](actuator.md), it can also be installed in a [microcontroller](microcontroller.md) as an upgrade.
